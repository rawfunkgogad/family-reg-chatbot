# 가족관계등록 법령·예규·선례 자동 수집 및 JSON 구축 시스템

대법원 사법정보공개포털([portal.scourt.go.kr](https://portal.scourt.go.kr/)) 및 국가법령정보 공동활용 Open API([open.law.go.kr](https://open.law.go.kr/))를 연동하여, **가족관계의 등록 등에 관한 법률**을 중심으로 한 **전체 법령체계도(모법, 대법원규칙, 위임 행정규칙, 특례법)** 및 **대법원 가족관계등록예규와 선례** 전수를 현행화하여 정제된 JSON 데이터로 구축하는 자동화 도구입니다.

---

## 📁 산출물 파일 구조 (`output/`)

| 파일명 | 내용 | 데이터 건수 | 파일 크기 | 데이터 출처 |
| :--- | :--- | :--- | :--- | :--- |
| **`family_law_hierarchy.json`** | **법령체계도 전체 통합본** (트리 구조 + 전수 본문) | 총 21개 규정 | 약 400 KB | 국가법령정보 공동활용 Open API |
| **`family_act_and_rule.json`** | 모법(법률) + 하위 대법원규칙 본문 및 조문 | 2건 (조문 284개) | 약 283 KB | 국가법령정보 공동활용 Open API |
| **`family_delegated_rules.json`** | 법률 및 규칙에서 직접 위임된 행정규칙(예규/지침) | 13건 | 약 16 KB | 국가법령정보 공동활용 Open API |
| **`family_related_special_laws.json`**| 법령체계도 상 연결된 관련 특례 법률 및 규칙 | 6건 | 약 85 KB | 국가법령정보 공동활용 Open API |
| **`family_rules.json`** | **대법원 가족관계등록예규** 전수 본문 (현행 기준) | 200건 | 약 2.75 MB | 대법원 사법정보공개포털 |
| **`family_precedents.json`** | **대법원 가족관계등록선례** 전수 본문 | 78건 | 약 0.56 MB | 대법원 사법정보공개포털 |
| **`data_summary.json`** | 대법원 예규 및 선례 요약 통계 | 1건 | < 1 KB | 대법원 사법정보공개포털 |

## 🚀 실행 스크립트

### 1. 국가법령정보센터 법령체계도 수집 (Open API)
```powershell
cd C:\Users\rawfu\.gemini\antigravity-ide\scratch\scourt-crawler
python -X utf8 run_law_hierarchy.py
```
- Open API 인증키(`familylawapi`)를 활용하여 공식 DRF 서비스(`target=lsStmd`, `target=law`, `target=admrul`)로부터 최신 현행 조문을 실시간 수집합니다.

### 2. 대법원 사법정보공개포털 예규·선례 수집
```powershell
cd C:\Users\rawfu\.gemini\antigravity-ide\scratch\scourt-crawler
python -X utf8 run_crawler.py
```
- 대법원 포털의 200개 현행 예규와 78개 선례 전체를 디렉토리 경로 및 조문 구조와 함께 수집합니다.
